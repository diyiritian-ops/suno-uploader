# 更新公告 · v30.5

**这次最重要的一条：断音修好了。**

以前每 9 秒会空 1.6 秒没声音，全片 21% 是静音——原因是上传后 Studio 又把速度加快了 1.26 倍。
现在改成不做二次变速，音频 1:1 还原：**速度与原版一致，不再有空档**。

---

## 其他改动

- **界面重做**：4 个标签页（上传 / 结果 / 作品库 / 积分），顶部 4 步引导
- **跑完直接给成品**：自动跳到「结果」页，封面 + 标题 + 一键打开，不用再手动找
- **缺段一键补**：有段没传上去会拦下导出，并给一个「只补缺的 N 段」按钮
- **进度显示剩余时间**：不再干等
- **运行日志已隐藏**（客户看不到细节，排错时菜单里有「复制运行日志」）
- **积分功能适配新版页面**，并会跳过平台塞的蜜罐题；连续不计数会自动停

## 升级提醒

- 移调参数现在是「保时长」的，**调大不会再把速度改快**，只会影响音质
- 建议用 **6–7**：过检率明显更高，且不再产生断音
- 从 0 开始（完全不动）虽然音质最好，但很容易被平台判为版权内容，会一直重试
